Interpretation
--------------
The proportional-capital experiment shows that FedAvg consistently reduces
loan-count defaults when capital grows with borrower volume. The return
difference is small. FedAvg has a higher return at 100 wholesalers, while
isolated RL has a slightly higher return at 50 and 250 wholesalers. The
evidence therefore supports a careful claim: federated borrower screening
improves default control in the complete proportional-capital scalability
range, but it does not uniformly dominate isolated RL on return.
