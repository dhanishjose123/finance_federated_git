EGT APR Model Selection Explanation
===================================

Goal
----
The goal was to select the best APR-learning model among several EGT-based
agents. The comparison focused especially on the new EGT agents that use the
same payoff signal family as pure RL, but update APR through EGT dynamics.


Models Compared
---------------
The run compared these main APR models:

1. Fin_RL
   - Pure tabular RL APR agent.
   - Uses Q-learning over APR actions.

2. Fin_EGT
   - Original EGT APR model.
   - Uses the utilization-based APR anchor plus EGT pressure.
   - Formula shape:
       APR = utilization_apr + egt_pressure

3. Fin_EGT_No_Utilization
   - EGT model without the utilization APR anchor.
   - Adjusts APR directly from the previous APR.
   - This was used to test how much of Fin_EGT's performance comes from the
     utilization anchor.

4. Fin_EGT_Pure_RL_Payoff
   - New EGT model using the pure-RL-style payoff signal.
   - Uses logit EGT update.

5. Fin_EGT_Pure_RL_Replicator
   - Same payoff signal, but with replicator dynamics.

6. Fin_EGT_Pure_RL_Fermi
   - Same payoff signal, but with Fermi imitation dynamics.

7. Fin_EGT_Pure_RL_Aspiration
   - Same payoff signal, but compares payoff against a fixed aspiration target
     instead of only a moving average.

Fixed APR baselines were also included:
   - fixed_6
   - fixed_8
   - fixed_10


Selection Method
----------------
All models were run under the same capital setting:

    Capital = 1,000,000

The selection metric was final capital. Higher final capital means the model
generated better capital growth under the tested simulation settings.

The payoff-based EGT models were compared against each other using the same
payoff weights. This made the comparison about the EGT update rule itself,
not about different reward tuning.


Observed Results
----------------
From the run:

    Fin_RL final capital:                         1,860,942.588
    Fin_EGT final capital:                        2,015,740.774
    Fin_EGT_No_Utilization final capital:         1,130,448.216
    Fin_EGT_Pure_RL_Payoff final capital:         1,002,558.148
    Fin_EGT_Pure_RL_Replicator final capital:       998,852
    Fin_EGT_Pure_RL_Fermi final capital:          1,067,453
    Fin_EGT_Pure_RL_Aspiration final capital:     1,002,318
    fixed_6 final capital:                          967,331.5
    fixed_8 final capital:                        1,089,978
    fixed_10 final capital:                       1,253,889

Overall winner:

    Fin_EGT

Best payoff-based EGT model:

    Fin_EGT_Pure_RL_Fermi


Why Fin_EGT Won Overall
-----------------------
Fin_EGT performed best overall because it still uses the utilization-based APR
anchor:

    APR = utilization_apr + egt_pressure

This means APR automatically responds to capital deployment. When utilization
changes, the base APR moves strongly even before the EGT pressure is applied.
That makes Fin_EGT partly a rule-based utilization pricing model and partly an
EGT model.

The large gap between Fin_EGT and Fin_EGT_No_Utilization shows that the
utilization anchor is a major contributor to performance.


Why Fermi Was Selected Among Pure-RL-Payoff EGT Models
------------------------------------------------------
Among the payoff-based EGT models, Fermi had the highest final capital:

    Fin_EGT_Pure_RL_Fermi = 1,067,453

The other payoff-based EGT variants were close to break-even:

    Logit/default    = 1,002,558.148
    Replicator       =   998,852
    Aspiration       = 1,002,318

Fermi likely performed better because it reacts more sharply to payoff
differences. The Fermi update converts payoff advantage into a switching
probability:

    imitation_prob = 1 / (1 + exp(-eta * 4 * payoff_gap))
    score = score + alpha * (imitation_prob - score)

This makes the APR score move more decisively when payoff improves or worsens.
The logit and replicator versions are smoother, but in this simulation they
appear too slow or too weak to improve APR meaningfully.


Selected Model
--------------
For the current payoff-based EGT experiment, the selected model is:

    Fin_EGT_Pure_RL_Fermi

Reason:

    It produced the highest final capital among the EGT models that use the
    pure-RL-style payoff signal and do not rely on the utilization APR anchor.


Important Caveat
----------------
Fin_EGT remains the best overall model in this run, but it is not a pure test
of EGT payoff learning because it includes the utilization APR anchor. If the
goal is best performance, Fin_EGT is currently strongest. If the goal is to
select the best pure payoff-based EGT update rule, Fermi is the best candidate
from this run.
