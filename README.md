# Reviewer Package

This folder contains the compact files required to review the manuscript, supporting documents, and reproducibility material for the adaptive blockchain-enabled federated finance study.

## Folder Contents

- `manuscript/`: current manuscript source, bibliography, compiled PDF, supplementary material, and manuscript figures.
- `review_documents/`: response/fact-check documents useful during reviewer or editor inspection.
- `code_and_results/`: simulation code, compact result summaries, trained Q-table examples, Hyperledger/Caliper artifacts, and experiment notes prepared for reproducibility.

## Notes

Large raw simulation workbooks and local build/cache files are intentionally excluded. The included result summaries and spreadsheets are the compact reviewer-facing artifacts used to support the manuscript tables and claims.

The refreshed Hyperledger chaincode file is available at:

`code_and_results/hyperledger/cardamom_11.js`
